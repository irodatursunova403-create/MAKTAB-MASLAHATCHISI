# Xavfsizlik Siyosati (Security Policy)

## Qoʻllab-quvvatlanadigan Versiyalar
Hozirda xavfsizlik yangilanishlari (security updates) bilan taʼminlanadigan versiyalar roʻyxati:

| Versiya | Qoʻllab-quvvatlanadi |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :white_check_mark: |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :white_check_mark: |

## Zaifliklar haqida xabar berish
Agar loyihamizda biror xavfsizlik muammosi yoki zaiflik (vulnerability) topsangiz, iltimos, quyidagi tartibda xabar bering:

1. **Qayerga yuborish kerak:** Muammoni ochiq (Public Issue) qilib yozmang. Uni toʻgʻridan-toʻgʻri **[elektron-pochtangiz@domain.com]** manziliga xat qilib yuboring.
2. **Javob berish vaqti:** Yuborilgan xabarlarni **[24-48 soat]** ichida koʻrib chiqamiz va sizga dastlabki javobni qaytaramiz.
3. **Natija:** Muammo tasdiqlansa, uni bartaraf etish ustida ish boshlaymiz va sizni jarayon haqida xabardor qilib turamiz.
